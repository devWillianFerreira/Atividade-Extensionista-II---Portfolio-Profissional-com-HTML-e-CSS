Portfólio Profissional com HTML e CSS

Projeto desenvolvido durante uma série de vídeos no YouTube, onde construo um portfólio completo do zero utilizando HTML e CSS.

O objetivo deste projeto é demonstrar boas práticas de desenvolvimento front-end, estruturação semântica de páginas web e criação de layouts modernos e responsivos.
